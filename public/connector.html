Private Real-Estate Portfolio Intelligence Connector

A private data-and-tools layer that connects directly to Claude, giving it verified, structured knowledge of a real multifamily property portfolio — so a real question about a building gets a correct, source-backed answer without anyone manually locating and uploading documents first.

This project runs on entirely fictional sample data during development. No real client, tenant, or financial information is used or shown here.

The problem

Claude is great at answering — the hard part is context

Claude can already summarize documents, compare files, and answer general real-estate questions. But it depends on someone supplying the right documents and business context every single time. This project removes that step by giving Claude a private, permanent, and verifiable memory of the portfolio behind the scenes.

Architecture

Six layers between the source files and Claude

Claude never gets raw database or file-system access — only a small set of controlled, read-only tools that return structured, cited answers.

The connector

8 read-only tools exposed to Claude

Built on the Model Context Protocol (MCP) — the same standard Claude uses for any custom connector — and verified with a real MCP client over both stdio and HTTPS transports.

resolve_property

Turns a name, alias, address, ownership entity, or accounting code into a canonical property record.

get_property_summary

Full briefing: profile, open findings, recent maintenance, top expenses, upcoming deadlines.

search_property_documents

Property-scoped document search — never crosses property boundaries.

get_expense_history

Deterministic totals by category and date range, from approved invoices only.

get_maintenance_history

Maintenance events with automatic repeat-issue detection and cost totals.

get_open_anomalies

Open findings — utility anomalies, repeat repairs, conflicting records.

get_contract_deadlines

Contracts with a termination-notice or expiry deadline inside a given window.

get_utility_anomalies

Flags billing periods above a trailing baseline, with estimated annual cost exposure.

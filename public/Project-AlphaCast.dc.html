Project question

Can a model rank future relative winners without seeing the future?

AlphaCast is built around ranking, not pretending to know an exact future price. Each score is evaluated against the realized sector-relative return of a security, then compared with a simple momentum baseline under the same walk-forward rules.

First version

A credible research foundation before a flashy backtest.

Implemented

  • Trailing momentum, volatility, drawdown, and market-relative features
  • 20-session sector-relative excess-return target
  • Expanding-window folds with a 20-session embargo
  • Momentum baseline and Ridge regression ranking
  • Monthly rank IC and quintile-spread diagnostics
  • Deterministic synthetic data and automated tests

Deliberately not claimed

  • No live or historical alpha claim
  • No price targets or trading recommendation
  • No live market or fundamental data yet
  • No invented Sharpe ratio or portfolio return
  • No evidence that machine learning beats the baseline
Why synthetic data first: it lets the code prove timing, leakage controls, and evaluation contracts before external data is introduced. The current Ridge example does not outperform momentum on the generated panel; that is useful evidence that the system will report an inconvenient result rather than manufacture one.

Next build

From research scaffold to real systematic equity platform.

The next phase adds provider-approved point-in-time data, fundamental features, tree-based models, sector and turnover constraints, realistic transaction costs, feature explanations, and model-degradation monitoring. Every addition will be evaluated through the same chronological validation gate.

AlphaCast is independent research software by Nathan Gomes. The first release uses synthetic data and is not investment advice.

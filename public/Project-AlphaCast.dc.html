03 / Machine-learning equity research

AlphaCast

A research workstation that ranks 98 US large caps by their expected sector-relative return over the next 20 trading sessions, tests five models under the same walk-forward rules, and turns the signal into a cost-aware portfolio it keeps monitoring.

Project question

Can machine learning rank next month's relative winners, out of sample, after costs?

AlphaCast does not predict prices. At every month-end it ranks each stock against its sector peers, using only information available at that close, then measures how the ranking performed over the following 20 sessions. A model earns credit only if it beats a plain 12-1 momentum ranking on identical folds, costs, and portfolio rules.

01

Point-in-time features

14 trailing price, risk, liquidity, and relative-strength inputs, ranked within each date.

02

Sector-relative target

The 20-session forward return minus the equal-weight return of the stock's sector.

03

Embargoed walk-forward

Expanding training windows stop 20 sessions before each test date, so labels never overlap.

04

Rank, trade, monitor

Rank IC and quintile spreads, a top-15 sleeve net of costs, then drift and health checks.

The application

Built as software people would use, not a notebook.

The live app is a multi-view workstation. It opens on a precomputed workspace built from a frozen Yahoo Finance snapshot, so the first screen loads instantly. New studies run in the background with progress reporting.

Findings

A modest, real signal that is not stationary.

Over 114 monthly out-of-sample folds (February 2017 to July 2026), Random Forest was the only model whose mean Rank IC was statistically distinguishable from zero. The linear models and gradient boosting did not clearly beat the momentum baseline after turnover. All five models are currently flagged as degraded: their last six months of ranking quality fall below their long-run record. AlphaCast surfaces that result instead of hiding it.

Engineering

Research controls and software built together.

Implemented

  • Frozen Yahoo Finance snapshot for 98 stocks plus live Yahoo and synthetic data sources, with a data-quality gate that drops partially published sessions
  • Within-date rank-normalised features and winsorised training labels
  • Momentum, Ridge, Elastic Net, Random Forest, and gradient boosting on identical embargoed folds
  • Live scoring of the latest close, occlusion attribution, quintile and regime diagnostics
  • Equal-weight top-ranked portfolio with turnover and basis-point costs
  • Monitoring statuses, population-stability feature drift, and attribution drift
  • FastAPI backend with background jobs, JSON and CSV export, dependency-free JavaScript workstation, pytest suite, Docker and Render deployment

Deliberately not claimed

  • No price targets, trading recommendation, or claim of established alpha
  • No point-in-time index membership: the universe is today's large caps, so results carry survivorship bias
  • No point-in-time fundamentals, delisting returns, borrow costs, taxes, or spread and impact model
  • No portfolio optimizer, sector constraints, or order routing
  • No hyperparameter search tuned on the test folds
Why the controls matter: every feature is known at the decision close, every label starts after it, and training stops 20 sessions before each evaluation. Models are refitted quarterly on weekly-sampled history, so a stale fit can only be older and cannot leak.

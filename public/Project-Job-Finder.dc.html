Project 03 — Automation

Job Finder Automation

A Python pipeline that collects job listings, filters them against role signals I actually care about, and writes out structured leads. Built because opening forty tabs a day is not a search strategy.

Role
Design and build
Stack
Python · BeautifulSoup · JSON
Status
Shipped — in personal use
Output
Structured JSON, reviewable by hand

The idea

The job search is an operations problem wearing a motivation costume.

The hard part of applying isn't writing the application — it's the bookkeeping around it. Which listings have I already seen, which ones are actually a match for my experience, which ones did I lose because I never wrote the link down. Doing that in a browser guarantees duplicate effort.

So I moved it out of the browser. The pipeline gathers listings once, scores them on signals I define, and hands back a file I can review in one sitting. The decision about where to apply stays mine; the tedium doesn't.

How it works

01

Collect

Walk a configured set of listing pages, parse the markup, and normalise every posting into the same shape — title, company, location, link, date seen.

02

Deduplicate

Match against everything seen before so reposts and cross-board duplicates don't come back around a second time.

03

Filter on role signals

Keyword and seniority rules push cloud, automation, and junior-development roles up, and drop the postings that are only nominally in scope.

04

Export

Write structured JSON that's readable by a human and importable anywhere — no proprietary format, no lock-in to the tool that made it.

What I learned

Scrapers break, so fail loudly

A page changes its markup and a naive parser quietly returns zero results, which looks identical to "no new jobs today". Each source now reports how many postings it found, so silence is distinguishable from failure.

Keep the human in the loop

An earlier version tried to auto-rank matches into a single "apply to this" answer. It was confidently wrong often enough that I stopped trusting it. Filtering and surfacing turned out to be more useful than deciding.

Be a polite client

Rate limiting, caching, and respecting what a site asks of automated traffic aren't optional extras. The tool only runs on sources where that's reasonable.
